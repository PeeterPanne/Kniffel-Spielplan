KNIFFEL – DIGITALER SPIELZETTEL

Dateien:
- index.html: App
- manifest.webmanifest: PWA-Metadaten
- sw.js: Offline-Caching
- icons/: App-Symbole

LOKAL TESTEN
Öffne index.html im Browser. Lokale Speicherung ist browserabhängig. Offline-PWA-Funktionen und Installation benötigen normalerweise HTTPS und das Bereitstellen aller Dateien auf einer Website.

AUF DEM IPHONE
1. Paket auf einen HTTPS-Webhost laden (z. B. GitHub Pages). Alle Dateien und den Ordner icons unverändert zusammen hochladen.
2. Die Website in Safari öffnen.
3. Teilen > Zum Home-Bildschirm.

APP STORE
Diese Version ist eine installierbare Web-App (PWA), noch keine native App-Store-App. Für eine Veröffentlichung im App Store braucht es anschließend eine native Hülle bzw. ein iOS-Projekt, Tests und die Erfüllung der jeweils aktuellen Apple-Richtlinien.
